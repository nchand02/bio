## 🚀 Deployment Instructions

### Step 1: Prepare Your Repository

1. Make sure you have a GitHub repository named `bio` (already exists at `nchand02/bio`)
2. Ensure you're on the `main` branch

### Step 2: Push Files to GitHub

```bash
# Navigate to your project directory
cd /Users/navdeepsinghchander/ws-IntelliJ/bio

# Initialize git if not already done
git init

# Add all files
git add index.html styles.css script.js README.md

# Commit changes
git commit -m "Add premium professional bio website"

# Add remote if not already added
git remote add origin https://github.com/nchand02/bio.git

# Push to GitHub
git push -u origin main
```

### Step 3: Enable GitHub Pages

1. Go to your repository: `https://github.com/nchand02/bio`
2. Click on **Settings** (gear icon)
3. Scroll down to **Pages** in the left sidebar
4. Under **Source**, select:
   - Branch: `main`
   - Folder: `/ (root)`
5. Click **Save**
6. Wait 1-2 minutes for deployment
7. Your site will be live at: `https://nchand02.github.io/bio/`

### Step 4: Verify Deployment

Visit `https://nchand02.github.io/bio/` to see your live website!

## 🔧 Customization

### Update Content

Edit `index.html` to update:
- Personal information
- Work experience
- Projects
- Skills
- Contact details

### Change Colors

Edit `styles.css` CSS variables in the `:root` section:
```css
:root {
    --primary-color: #2563eb;
    --accent-color: #0ea5e9;
    /* Add more custom colors */
}
```

### Modify Sections

Add or remove sections in `index.html` following the existing pattern:
```html
<section id="section-name" class="section">
    <div class="section-header">
        <h2 class="section-title">Section Title</h2>
    </div>
    <!-- Your content -->
</section>
```
